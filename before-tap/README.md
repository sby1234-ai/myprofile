# 누르기 전에

문자나 메신저로 링크를 받은 사람이 **누르기 전에** 붙여 넣거나 공유하면, 2024년 한국인터넷진흥원(KISA)이 탐지한 피싱 주소 131,752건과 대조해 위험 신호를 알려 주는 앱입니다.

- 공개 주소: https://sby1234-ai.github.io/myprofile/before-tap/
- 바탕이 된 논문: 「명절 연휴 직전 피싱사이트 탐지량의 변화」([t10-holiday-phishing](https://github.com/sby1234-ai/t10-holiday-phishing))

## 논문의 결과를 이렇게 씁니다

| 논문이 밝힌 것 | 앱이 하는 일 |
|---|---|
| "명절 직전에 피싱이 늘어난다"는 경고는 2024년 자료에서 확인되지 않았습니다. 설 직전 2주는 평소의 0.53배, 추석 직전 2주는 0.57배였습니다. | 날짜로 위험을 가려낼 수 없으므로 **받을 때마다** 확인하게 합니다. 「피싱은 날짜를 가리지 않습니다」에서 날짜를 골라 그날의 탐지 수를 평소(하루 293.7개)와 비교해 볼 수 있습니다. |
| 분석에 쓴 2024년 KISA 탐지 주소 131,752건 | 받은 링크를 이 목록과 대조합니다. 탐지 주소의 49.1%가 단축 주소였다는 것처럼 자료에서 자주 보인 특징을 주의 신호로 알려 줍니다. |

## 사용자가 할 일 세 가지

1. **받은 링크를 넣습니다.** 문자를 통째로 붙여 넣어도 되고(안의 링크를 모두 찾음), 「붙여넣기」 버튼을 써도 되며, 안드로이드는 홈 화면에 추가한 뒤 문자에서 링크를 길게 눌러 **공유 → 누르기 전에**로 보낼 수 있습니다.
2. **결과를 봅니다.** 링크마다 「위험」(목록에 있음) / 「주의」(주의 신호) / 「미확인」(목록에 없음) 도장 중 하나와 그 근거, 해야 할 일이 나옵니다. 목록에 없다고 "안전"이라고 하지 않습니다.
3. **날짜를 골라 봅니다.** 2024년의 날짜를 고르면 그날 탐지된 피싱 주소 수가 평소의 몇 배인지 나옵니다. 366일 모두 탐지됐다는 것을 직접 확인할 수 있습니다.

## 내 컴퓨터에서 실행하기 (이 묶음)

1. ZIP의 압축을 새 폴더에 모두 풉니다.
2. `before-tap` 폴더의 `index.html`을 더블클릭해 브라우저로 엽니다. 서버나 설치가 필요 없습니다.
3. 「예시 문자로 해 보기」를 누르면 결과 세 가지(위험 · 주의 · 미확인 도장)가 나옵니다.

> 공유하기 연결과 오프라인 저장은 인터넷 주소(https)로 열었을 때만 동작합니다. 더블클릭으로 열면 붙여 넣기와 판정, 날짜 확인은 그대로 됩니다.

## 점검하기 (선택)

```bash
node tests/unit.js                                  # 판정 로직 26개 항목
python3 -m http.server 8765 --bind 127.0.0.1 &      # 브라우저 점검용 임시 서버
node tests/e2e.js http://127.0.0.1:8765/            # 실제 브라우저로 25개 항목 (Playwright 필요)
```

## 데이터와 비밀값

- 앱에 들어 있는 데이터는 공공데이터포털의 「한국인터넷진흥원_피싱사이트_20241231」(이용허락범위 제한 없음)에서 만든 **피싱 주소 목록**뿐입니다. 사람의 이름·전화번호 같은 개인정보는 들어 있지 않습니다.
- 데이터 다시 만들기: `python3 tools/prepare_data.py <논문 저장소 폴더>` → `data/lookup.js`, `data/paper.js`. 같은 원자료면 같은 결과가 나옵니다.
- AI 서비스나 외부 API를 부르지 않으므로 **API 키·비밀번호·환경 변수가 필요 없습니다.**
- 입력한 문자와 링크는 브라우저 안에서만 확인하고 어디로도 보내지 않습니다. 결과 화면의 주소는 누를 수 있는 링크로 만들지 않습니다.

## 판정 방법

| 결과 | 조건 |
|---|---|
| 위험 | 주소 전체(경로까지)가 목록에 있거나, 도메인이 목록에 있음 |
| 주의 | 단축 주소 / 같은 상위 도메인이 탐지됨 / 탐지 주소에서 1% 이상 쓰인 낯선 끝부분(.icu, .one 등) / IP 주소 / 특수 문자 도메인(xn--) / 주소 안의 @ / 회사 이름이 들어 있지만 공식 도메인이 아님 |
| 미확인 | 위 어느 것에도 해당하지 않음. 그 뒤에 새로 생긴 피싱 주소는 목록에 없으므로 안전하다는 뜻은 아님 |

네이버·카카오·구글처럼 누구나 페이지나 단축 주소를 만들 수 있는 서비스는 도메인 전체를 위험으로 보지 않고, 주소 전체가 같을 때만 「위험」으로 판정합니다.

## 글꼴

제목과 도장에는 Noto Serif CJK KR Black에서 필요한 글자만 뽑은 `fonts/seal-subset.woff`(약 22KB)를 씁니다. 외부 글꼴 서버를 부르지 않습니다. 라이선스는 SIL Open Font License 1.1이며 `fonts/LICENSE-NotoSerifCJK.txt`에 있습니다.

## 한계

- 목록은 2024년 한 해치입니다. 새 피싱 주소는 「주의 신호」로만 잡을 수 있습니다.
- 주의 신호는 탐지 주소에서 자주 보인 특징일 뿐, 그 특징이 있다고 모두 피싱인 것은 아닙니다.
- 아이폰은 웹 앱 공유하기 연결을 지원하지 않아 붙여넣기만 쓸 수 있습니다.
- 결과는 참고용입니다. 이미 눌렀거나 정보를 입력했다면 국번 없이 118(KISA 상담센터)에 상담하세요.
