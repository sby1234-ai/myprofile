## 검증 안내서 (과제 8 — 패스키 로그인)

### 1. 어디로 가나요?

포트폴리오 페이지 아래쪽의 "비공개 자리" 섹션으로 이동합니다.

https://sby1234-ai.github.io/myprofile/

### 2. 무엇을 하나요?

1. "새 계정 만들기"에 새 계정 이름과 패스키 이름을 입력하고 `패스키 등록하고 계정 만들기`를 누릅니다.
2. 브라우저 창에서 패스키를 만들고 PIN(또는 지문)으로 본인 확인을 합니다.
3. "패스키로 로그인"에 같은 계정 이름을 입력하고 `패스키로 로그인`을 누른 뒤 본인 확인을 합니다.
4. 로그아웃한 뒤 같은 계정으로 다시 로그인합니다.

### 3. 무엇이 보이면 통과인가요?

* 페이지 어디에도 비밀번호 입력창이 없습니다.
* 로그인 전에는 비공개 자료가 보이지 않고, 로그인/계정 만들기 화면만 보입니다.
* 로그인하면 비공개 메모 3개와 등록된 패스키 목록이 보입니다.
* 아래 "요청·응답 기록"에 로그인할 때마다 서로 다른 challenge 값과 `200` 응답이 남습니다.

### 4. 안 될 때는?

* 패스키 창이 뜨지 않거나 예전 동작을 하면 `Ctrl+Shift+R`로 강력 새로고침 후 다시 시도합니다.
* "이미 사용 중인 계정 이름"이 뜨면 다른 계정 이름으로 등록합니다.
* 서명 검증 실패가 뜨면 등록할 때 저장한 곳(Google 비밀번호 관리자 등)의 패스키를 골랐는지 확인합니다.

## 정상 동작 (실제 확인)

* [x] 새 계정(`qwer`) 패스키 등록 성공 — Google 비밀번호 관리자에 저장

## 아직 방어하지 못한 것

사이트에 Content-Security-Policy가 없고, 로그인 후 access_token과 refresh_token이 브라우저 저장소(localStorage)에 저장됩니다. 페이지에 스크립트를 끼워 넣는 XSS가 가능해지면 토큰을 읽어가 비공개 자료를 조회할 수 있으며, 이에 대한 별도 방어는 없습니다.
