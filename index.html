IT 학습자입니다.

새로운 기술을 직접 실습하고, 문제가 생기면 원인을 찾아 해결하는 과정을 중요하게 생각합니다.

이 페이지는 누구를 위한 것인가? IT 분야에서 함께 배우고 일할 사람에게 저의 관심 분야와 문제 해결 방식, 학습 결과를 보여주기 위한 페이지입니다.

현재 관심 분야

서버 · 네트워크 · Linux · 웹 기술

직접 구성하고 테스트하면서 기술을 이해하는 방식을 선호합니다.

제가 보여주고 싶은 3가지

01. 문제 해결

상황
서버나 웹페이지를 직접 구성하면서 예상하지 못한 오류를 만나는 상황이 있습니다.
행동
설정을 하나씩 확인하고 오류 메시지와 동작 결과를 비교하면서 원인을 좁혀갑니다.
결과
문제가 발생한 지점을 찾아 수정하고 정상적으로 동작하는지 다시 확인합니다.

02. 직접 실습

상황
새로운 IT 기술이나 도구를 처음 접했을 때가 있습니다.
행동
설명만 읽는 것보다 직접 설치하고 설정하면서 기능을 확인합니다.
결과
단순히 개념을 아는 것에서 끝나지 않고 실제 동작 과정을 경험합니다.

03. 꾸준한 학습

상황
익숙하지 않은 기술을 배우면서 모르는 부분이 생깁니다.
행동
작은 기능부터 직접 따라 하고 결과를 확인하면서 하나씩 범위를 넓힙니다.
결과
학습한 내용을 실제 페이지와 서버 구성 같은 결과물로 연결하려고 합니다.

공개 가능한 근거

직접 만든 웹페이지

이 페이지 자체가 학습 내용을 직접 적용하여 만든 결과물입니다. HTML 구조를 작성하고 CSS로 화면을 구성한 뒤, GitHub Pages를 이용해 실제 공개 페이지로 연결했습니다.

페이지 구조 작성 → 화면 구성 → 공개 → 브라우저 검사 → 오류 및 화면 문제 수정 순서로 작업했습니다.

공개 범위

공개할 것

  • IT 분야에 대한 관심
  • 학습 방식과 강점
  • 직접 만든 결과물

공개하지 않을 것

  • 전화번호
  • 개인 이메일 주소
  • 상세 주소 및 기타 개인정보
개인 정보는 공개하지 않고 학습 결과와 관심 분야만 보여주는 포트폴리오입니다.
