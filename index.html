문제 해결

상황

서버나 웹페이지를 직접 구성하면서 예상하지 못한 오류를 만나는 상황이 있습니다.

행동

설정을 하나씩 확인하고 오류 메시지와 동작 결과를 비교하면서 원인을 좁혀갑니다.

결과

문제가 발생한 지점을 찾아 수정하고 정상적으로 동작하는지 다시 확인합니다.

직접 실습

상황

새로운 IT 기술이나 도구를 처음 접했을 때가 있습니다.

행동

설명만 읽는 것보다 직접 설치하고 설정하면서 기능을 확인합니다.

결과

단순히 개념을 아는 것에서 끝나지 않고 실제 동작 과정을 경험합니다.

꾸준한 학습

상황

익숙하지 않은 기술을 배우면서 모르는 부분이 생깁니다.

행동

작은 기능부터 직접 따라 하고 결과를 확인하면서 하나씩 범위를 넓힙니다.

결과
