나의 강점 3가지

말보다 실제 행동과 결과를 중심으로 정리했습니다.

01. 직접 해결하는 편

문제가 생겼을 때 원인을 확인하고 직접 설정을 바꿔가며 해결합니다.

상황: 실습 환경에서 예상대로 동작하지 않는 문제가 발생했습니다.
행동: 설정과 로그를 하나씩 확인하며 원인을 찾았습니다.
결과: 문제 원인을 확인하고 정상적으로 동작하도록 수정했습니다.

02. 새로운 것을 배우는 편

익숙하지 않은 기술도 직접 따라 해보고 결과를 확인하면서 익힙니다.

상황: 처음 접하는 IT 기술을 실습해야 했습니다.
행동: 공식 문서와 실습 내용을 참고해 직접 환경을 구성했습니다.
결과: 직접 실행해보면서 기본적인 동작 과정을 이해했습니다.

03. 확인하는 습관

작업이 끝났다고 바로 넘어가지 않고 실제 결과가 맞는지 다시 확인합니다.

상황: 만든 결과물이 실제 환경에서 정상적으로 보이는지 확인해야 했습니다.
행동: 다른 화면 크기와 브라우저에서 결과를 다시 확인했습니다.
결과: 화면 잘림과 가로 넘침 등의 문제를 수정했습니다.

공개 범위

필요한 정보만 공개하고 개인정보와 비밀값은 공개하지 않습니다.

공개할 것

  • IT 관련 관심 분야
  • 직접 수행한 실습과 결과
  • 문제를 해결하는 방식과 강점

공개하지 않을 것

  • 주소와 전화번호
  • 개인 이메일과 계정 정보
  • 비밀번호, 토큰, API 키 등 비밀값
개인 식별 정보와 비밀값을 포함하지 않은 포트폴리오 페이지입니다.
